# OYEU-S
# ORMAN YANGINI ERKEN UYARI SİSTEMİ
**TKGM Ada-Parsel Tabanlı Akıllı Sensör Ağı**

---

## 1. PROJE ÖZETİ

Kırıkkale Kent Ormanı'na yerleştirilen numaralandırılmış sensör ağı ile yangınları anında tespit eden ve tam konum bilgisini (ada, parsel, sensör numarası) Bluetooth üzerinden ileten erken uyarı sistemi.

---

## 2. SİSTEM BİLEŞENLERİ

### 2.1. Temel Donanım
- **Arduino Nano** - Ana kontrolör
- **MQ-2 Duman Sensörü** - Yangın tespiti
- **HC-05 Bluetooth Modülü** - Kablosuz iletişim
- **LED Göstergesi** - Görsel uyarı
- **Test Butonu** - Manuel kontrol
- **Solar Panel + Pil** - Güç kaynağı

### 2.2. Teknik Özellikler
- **7/24 kesintisiz izleme**
- **30 saniyede bir sistem durumu raporu**
- **Anında yangın alarmı**
- **Düşük güç tüketimi**
- **Kolay kurulum ve bakım**

## 4. ELEKTRONİK BAĞLANTI ŞEMASI

### 4.1. Arduino Nano Bağlantıları
```
A0   → MQ-2 Sensör (OUT pin)
D2   → Test Butonu (GND'ye bağlı)
D10  → Bluetooth RX
D11  → Bluetooth TX
D13  → LED (+)
5V   → Tüm modül VCC'leri
GND  → Tüm GND bağlantıları
```

### 4.2. Bağlantı Notları
- MQ-2 sensörü ağaç gövdesine 2-3 metre yükseğe
- Bluetooth modülü açık alana yerleştirilmeli
- Güneş paneli güneye bakacak şekilde
- Su geçirmez muhafaza kullanılmalı

## 6. TAM ÇALIŞAN KAYNAK KODU

```cpp
// Kırıkkale Kent Ormanı - Sensör No: 3
#include <SoftwareSerial.h>

#define MQ2_PIN A0
#define LED_PIN 13
#define BUTTON_PIN 2

SoftwareSerial bluetooth(10, 11);

// AYARLAR - HER SENSÖRDE DEĞİŞTİR!
int sensörNo = 3;
int adaNo = 34;
int parselNo = 43;
String konum = "Kırıkkale Kent Ormanı";
int yanginEsik = 400;

void setup() {
  pinMode(LED_PIN, OUTPUT);
  pinMode(BUTTON_PIN, INPUT_PULLUP);
  bluetooth.begin(9600);
  
  delay(1000);
  bluetooth.println("=== ORMAN YANGIN SENSORU ===");
  bluetooth.println("Sensor: " + String(sensörNo) + ". sensör");
  bluetooth.println("Konum: " + String(adaNo) + " ada " + String(parselNo) + " parsel");
  bluetooth.println("Durum: AKTIF");
  bluetooth.println("========================");
}

void loop() {
  if(digitalRead(BUTTON_PIN) == LOW) {
    testGonder();
    delay(5000);
  }
  
  int duman = analogRead(MQ2_PIN);
  
  if(duman > yanginEsik) {
    yanginAlarmi(duman);
  }
  
  static unsigned long sonOkuma = 0;
  if(millis() - sonOkuma > 30000) {
    normalVeriGonder(duman);
    sonOkuma = millis();
  }
  
  delay(1000);
}

void yanginAlarmi(int dumanDegeri) {
  for(int i=0; i<10; i++) {
    digitalWrite(LED_PIN, HIGH);
    delay(200);
    digitalWrite(LED_PIN, LOW);
    delay(200);
  }
  
  String alarmMesaji = "🚨 ACİL YANGIN UYARISI! ";
  alarmMesaji += String(adaNo) + " ada " + String(parselNo) + " parsel nolu ";
  alarmMesaji += String(sensörNo) + ". sensör yangın tespit etti. ";
  alarmMesaji += "Duman seviyesi: " + String(dumanDegeri);
  
  bluetooth.println(alarmMesaji);
  
  for(int i=0; i<18; i++) {
    digitalWrite(LED_PIN, HIGH);
    delay(5000);
    digitalWrite(LED_PIN, LOW);
    delay(5000);
    
    if(i % 3 == 0) {
      bluetooth.println("⚠️ Yangın alarmı devam ediyor: " + String(adaNo) + " ada " + String(parselNo) + " parsel");
    }
  }
}

void normalVeriGonder(int duman) {
  String normalMesaj = "✅ Normal durum: ";
  normalMesaj += String(adaNo) + " ada " + String(parselNo) + " parsel nolu ";
  normalMesaj += String(sensörNo) + ". sensör aktif. ";
  normalMesaj += "Duman: " + String(duman);
  
  bluetooth.println(normalMesaj);
}

void testGonder() {
  bluetooth.println("🔧 TEST MESAJI");
  bluetooth.println(String(adaNo) + " ada " + String(parselNo) + " parsel nolu");
  bluetooth.println(String(sensörNo) + ". sensör test ediliyor...");
  bluetooth.println("Durum: ÇALIŞIYOR");
  bluetooth.println("----------------------------");
}
```

## 8. KURULUM ve BAKIM

### 8.1. Sensör Kurulumu
1. Kod yükle (sensör numarasını ayarla)
2. Fiziksel montaj (ağaç gövdesi)
3. Bluetooth testi
4. Duman testi (çakmak)

### 8.2. Periyodik Bakım
- **Haftalık**: Test butonu kontrolü
- **Aylık**: Sensör temizliği
- **3 Aylık**: Pil/güneş paneli kontrolü
- **Yıllık**: Donanım yenileme

### 8.3. Sorun Giderme
| Problem | Çözüm |
|---------|--------|
| Bağlantı yok | Bluetooth eşleştirmeyi kontrol et |
| Yanlış alarm | Duman eşiğini ayarla (yanginEsik) |
| Pil bitiyor | Güneş paneli açısını kontrol et |
